# Getting help

- **Docs** — <https://docs.convilyn.corenovus.com> is the first stop (install, quickstart, API
  reference, changelog).
- **Questions / how-do-I** — open a [Question issue](../../issues/new/choose) or
  start a [Discussion](../../discussions) if enabled.
- **Bugs** — open a [Bug report](../../issues/new/choose) with a minimal repro.
- **Feature ideas** — open a [Feature request](../../issues/new/choose); note that
  behaviour changes are upstreamed into Convilyn's monorepo, so a maintainer will
  confirm the direction before implementation (see [CONTRIBUTING.md](CONTRIBUTING.md)).
- **Security** — **do not** use public channels; see [SECURITY.md](SECURITY.md).

Please **do not** email individual maintainers for support — using the issue
tracker keeps answers searchable for the next person.

This is a community mirror maintained on a best-effort basis. For commercial /
SLA-backed support, contact the Convilyn team via <https://docs.convilyn.corenovus.com>.
