# Maintainers — `convilyn-python`

Maintainers review + merge community PRs, run the upstreaming bridge into the
monorepo, cut releases, and triage. See [GOVERNANCE.md](GOVERNANCE.md) for roles and
how to become one.

The authoritative list is the GitHub team **`@CoreNovus/sdk-maintainers`** (which
`CODEOWNERS` routes reviews to). Security reports go to
**`@CoreNovus/security`** — see [SECURITY.md](SECURITY.md).

| Area | Owner |
|---|---|
| `convilyn` package + this mirror | `@CoreNovus/sdk-maintainers` |
| Security response | `@CoreNovus/security` |

To reach the maintainers for anything non-sensitive, open an issue or a
[Discussion](https://github.com/CoreNovus/convilyn-python/discussions).
